# 08. Technical Glossary
**Status:** [VERIFIED]

- **Air-Gap:** Complete logical and physical isolation from external networks or the public internet.
- **AST (Abstract Syntax Tree):** Tree representation of source syntax used here to evaluate math formulas safely without `eval()`.
- **Bcrypt:** Blowfish-based adaptive password-hashing algorithm with salt and work factor.
- **ChromaDB:** Local embedded vector database used for semantic similarity search.
- **Cryptographic Hash Chain:** Append-only ledger where each block contains the SHA-256 hash of the preceding block.
- **JTI (JWT ID):** Unique UUID embedded in JSON Web Tokens allowing server-side token revocation before expiration.
- **LangGraph:** Cyclic state machine orchestration framework for deterministic agentic workflows.
- **LLaVA:** Open-weight vision-language model combining CLIP visual encoder with Vicuna/LLaMA LLM.
- **Nomic Embed Text:** Open-weight 768-dimensional text embedding model optimized for dense RAG retrieval.
- **Open-Weight Model:** Machine learning models whose weights are freely downloadable and executable on private hardware.
- **PyMuPDF (`fitz`):** C-backed Python library for rapid PDF text parsing and high-resolution page rasterization.
- **RAG (Retrieval-Augmented Generation):** Technique retrieving external verified document chunks to ground model answers.
- **RBAC:** Role-Based Access Control restricting system features based on user roles (`admin`, `lead_engineer`, etc.).
- **Tesseract OCR:** Open-source LSTM optical character recognition engine converting images/scans to text.
