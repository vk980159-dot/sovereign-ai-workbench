# 02. Use Case: Heavy Machinery Field Inspector
**Status:** [VERIFIED]

- **Role:** Inspects turbines, generators, and compressors during scheduled turnarounds.
- **Workflow:** Takes photos of bearing assemblies (`inspection_photo.png`) and scans handwritten vibration inspection logs (`scanned_turbine_inspection_report.pdf`).
- **Processing:** LLaVA diagnoses fatigue spalling; Tesseract digitizes vibration readings (8.42 mm/s).
- **Deliverable:** Inspection Verification Report in PDF.
