# 00. SIH26117 Official Requirements Breakdown
**Status:** [VERIFIED]

## Official Problem Statement (SIH26117)
"Sovereign On-Premise Agentic AI Workbench using Open-Weight Multimodal LLMs for Confidential Industrial Work."

## Mandated Core Pillars
1. 100% on-premise execution with zero cloud AI API calls.
2. Open-weight multimodal models (text, vision, embeddings).
3. Goal-directed agentic planning, execution, and verification.
4. Multimodal ingestion (scanned PDFs, photographs, SOPs).
5. Authentic Microsoft Office and PDF deliverables.
6. Mathematical proof of log integrity and auditability.
